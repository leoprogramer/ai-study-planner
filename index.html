Prompt Maestro
Copia y pégalo en ChatGPT / Claude / Gemini. La IA debe responder solo JSON.
Escribe un tema arriba para generar el Prompt Maestro...
Flujo: 1) Copiar prompt → 2) Enviar a ChatGPT → 3) Copiar el JSON que responde → 4) Importar aquí.
El prompt obliga a la IA a no añadir texto extra ni markdown.
¿Cómo funciona?
  1. Escribes el tema (ej: Docker).
  2. La app genera un prompt blindado.
  3. Lo pegas en tu IA favorita.
  4. Copias el JSON que te devuelve.
  5. Lo importas y se crea el dashboard automáticamente.
  6. Haces seguimiento diario, pomodoro, notas y estadísticas.
